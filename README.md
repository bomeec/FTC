# matchCourt

테니스 복식 코트 배정 웹 앱. 멤버/코트/라운드를 설정하면 매 라운드 코트별 인원을 자동 배정합니다.

## 주요 규칙

### 인원 구성

- 매 라운드 전원 참여(쉬는 사람 없음)
- 게임 코트는 항상 4명(복식). 랠리 코트는 4명 이하 허용
- 멤버가 모자라면 남는 인원 부족분을 랠리 코트에서 뺌 (예: 11명 → 랠리3, 10명 → 랠리2, 9명 → 랠리1, 8명 → 랠리 미운영)
- 멤버 수 범위: 게임 좌석 수 이상 ~ 전체 좌석 수 이하 (범위를 벗어나면 에러)

### 코트 타입 (성별 구성)

- 남복(남4) / 여복(여4) / 혼복(남2여2) / 잡복(남3여1·여3남1)
- 잡복(홀수 구성)은 최소화하고, 생길 경우 남3여1보다 여3남1을 선호
- 잡복은 가능한 한 랠리 코트로 보내 게임 코트를 깔끔하게 유지
- 4라운드 중 남복·여복 최소 1회씩 포함
- 혼복은 각 팀이 남1여1이 되도록 분할

### 코트 역할 (랠리 / 게임)

- 랠리 코트에 있던 사람은 다음 라운드 게임 코트로 (soft 규칙)
  - 기본적으로 이 규칙을 지키되, premium 게임 횟수 같은 더 중요한 제약과 충돌하면 자동으로 완화함
  - 완화가 적용되면 결과에 안내 메시지가 표시됨
- 랠리 코트는 경기가 아니라 명단만 표시 (팀 분할·타입 분류 없음)

### 게임 횟수 목표

- premium 멤버: 남성은 남복 ≥1회 / 여성은 여복 ≥1회, 혼복 ≥1회, 게임 코트 ≥3회
- guest 멤버: 게임 코트 ≥2회

### 자동 완화 (단계적)

목표 제약을 모두 만족하는 배정을 찾지 못하면, 제약을 단계적으로 낮춰 재시도하고 완화한 내용을 결과에 경고로 표시합니다. 완화 순서:

1. 랠리→다음 라운드 게임 규칙 완화
2. premium 최소 게임 횟수 하향 (3 → 2)
3. guest 최소 게임 횟수 하향 (2 → 1)

여유 있는 구성(예: guest가 넉넉)에서는 완화 없이 목표를 그대로 지킵니다. 인원이 적거나 성비가 치우쳐 모든 단계로도 불가능하면, 가장 근접한 배정과 경고를 표시합니다.

## 파일

- `index.html` — 웹 UI (설정창에서 멤버·코트·라운드 편집, 배정 결과, 멤버별 통계). 설정은 브라우저 localStorage에 저장되고 info.json 내보내기 가능. 멤버는 이름·성별(M/W)·타입(premium/guest)을 가짐
- `assign.js` — 배정 로직 (브라우저/Node 겸용)
- `info.json` — 기본 멤버·코트·라운드 설정
- `run.js` — Node에서 결과 확인용 (`node run.js [seed]`)
- `server.js` — 로컬 개발 서버 (`node server.js`) — 배포에는 불필요

## 로컬 실행

```bash
node server.js
# http://localhost:8000 접속
```

## 배포 (GitHub Pages)

정적 사이트이므로 `index.html`이 레포 루트에 있으면 GitHub Pages로 바로 서빙됩니다.
Settings → Pages → Branch: `main` / Folder: `/ (root)`.
